# Contributing

Use an issue to discuss substantial changes before implementation. Keep pull requests focused, add tests for changed behavior, update user-facing documentation, and ensure all automated checks pass.

Do not commit credentials, private paths, licensed pseudopotentials, model weights, raw simulation outputs, or datasets without explicit redistribution permission. Report benchmark methods and failures as carefully as successful results.

By contributing, you represent that you have the right to submit the work under the repository's current license terms.
