# Historical design records

These records preserve design history and are **not authoritative operating documentation**.
The current manual and package code supersede them.

- `HPCA_PRODUCTION_PLAN.md` — implementation plan and dated status.
- `PROPOSED_HPCA_WORKFLOW.md` — proposed production architecture used during the refactor.
- `HPCA_END_TO_END_WORKFLOW.md` — earlier end-to-end contract draft.
- `HPCA_WORKFLOW.md` — legacy unified ASCII workflow.
- `hpca/orchestrator/PLAN.md` — earlier orchestrator architecture plan.

They are retained in Git history and temporarily at their legacy paths for external link
compatibility. New documentation must not link to them as current instructions. Once external
consumers have migrated, they may be moved mechanically into this directory without losing
history.
